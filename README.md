# Brainf**k Crust

A Brainfuck interpreter written in Rust following the rules of Crust 

The project is inspired by the [Crust](https://github.com/tsoding/crust) rules created by [Tsoding](https://github.com/tsoding). Created only for Windows.

## Build

To compile, run the build file:
```powershell
./build.bat
```
